## About me

- **Domain focus:** 2+ years in Cash Management Services (CMS), core transaction banking products, and transaction banking architecture.
- **Systems and rails:** Double-entry ledgers, virtual account management (VAM), digital escrow workflows, and payment-clearing concepts for ISO 20022, UPI, ULI, IMPS, NACH, RTGS, NEFT, SWIFT, and ACH.
- **AI and LLM integration:** Building fintech workflows with hosted inference, local runtimes, document intelligence, and agent orchestration.
- **Writing:** I write about financial systems architecture and transaction rails at [Intent Curiosity Sphere](https://intentcuriositysphere.substack.com).

## Selected projects

### B2B Virtual Account Ledger

[Repository](https://github.com/amityoshops-dev/b2b-virtual-account-engine) · [Operations portal](https://b2b-ledger-portal.vercel.app) · [API docs](https://b2b-virtual-account-engine.onrender.com/docs)

Virtual account management and double-entry ledger platform for transaction banking and treasury operations. Uses FastAPI, SQLAlchemy, PostgreSQL on Neon, Next.js, Tailwind CSS, and ISO 20022 payment messages.

### Institutional Ledger and Auto-Reconciliation

[View the repository](https://github.com/amityoshops-dev/institutional-ledger-core)

Multi-tenant virtual account and ledger reference system featuring Redis idempotency, PostgreSQL, ISO 20022 statement ingestion, and OpenTelemetry instrumentation.

### TBG / CMS Core Transaction Banking Engine

[View the repository](https://github.com/amityoshops-dev/TBG-Engine-)

Go-based corporate cash-management payout engine with a PostgreSQL double-entry ledger, Redis coordination, Kafka, ISO 20022 messaging, and Postman/Newman contract tests. Includes Splunk observability configurations.

### NPCI Payment Rails Simulator

[View the repository](https://github.com/amityoshops-dev/npci-b2b-engine)

Explores UPI, IMPS, and NACH payment flows with FastAPI, SQLAlchemy, and Pydantic, including initiation, clearing, settlement, and reconciliation.

### CareerTrace AI Agent

[View the repository](https://github.com/amityoshops-dev/CareerTrace)

Local-first job-application intelligence agent using FastAPI, LangGraph, Gemini, SQLite, and LangSmith, with document processing for resumes.

### Multi-Provider AI Router

[View the repository](https://github.com/amityoshops-dev/free-ai-router) (private)

Gradio chat app that discovers models across providers and routes prompts by task, with provider cooldowns and automatic failover.

### FinPulse Analytics

[View the repository](https://github.com/amityoshops-dev/finpulse)

Streamlit analytics prototype using Pandas, NumPy, and Altair.

### FlowCase Payment Dashboard

[View the repository](https://github.com/amityoshops-dev/flowcase)

React and Vite dashboard prototype for exploring payment rails and transaction cases; deployed with GitHub Pages Actions.

### Reverse-Pitch Settlement Calculator

[View the repository](https://github.com/amityoshops-dev/Reverse-Pitch-Engine-Brain) (private)

FastAPI settlement-split calculator with versioned fee schedules. Supabase schema and Decentro/Setu sandbox connections are documented as planned work and are not yet wired into the app.
